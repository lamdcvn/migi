=== VT Bulk Deals – Mua nhiều giảm giá ===
Requires Plugins: woocommerce
Stable tag: 1.0.0

Bảng deal theo số lượng trên trang sản phẩm (kiểu Flatsome Dynamic Pricing):
- Thẻ chọn: 1 sản phẩm / 2 sản phẩm (Tiết kiệm 10%) / 3+ sản phẩm (Tiết kiệm 20%)
- Badge tuỳ chỉnh chữ + màu: "Phổ biến nhất", "Giá tốt nhất", "Thường mua"...
- Bấm thẻ => tự đổi ô số lượng; đổi số lượng => tự chọn thẻ tương ứng
- Hỗ trợ sản phẩm đơn giản và có biến thể (giá cập nhật theo biến thể)
- Giỏ hàng / mini-cart: giá gạch ngang + "Deal: Bạn tiết kiệm xx", dòng "Tiết kiệm từ deal" ở tổng
- Đơn hàng lưu meta "Deal số lượng"

Cài đặt chung: WooCommerce → Deal số lượng
Từng sản phẩm: Sửa sản phẩm → Dữ liệu sản phẩm → tab "Deal số lượng" (Dùng chung / Tuỳ chỉnh / Tắt)
